# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

ผู้ซื้อเสื้อผ้าออนไลน์ โดยเฉพาะคนเมืองที่อยากเลือกเสื้อผ้าจากสีที่เข้ากับตนเอง และต้องการเห็นความสัมพันธ์ระหว่าง personal colour, เสื้อผ้า และลุคก่อนตัดสินใจซื้อ

## Product Purpose

MatchA เป็น e-commerce เสื้อผ้าที่ช่วยให้ผู้ใช้ค้นหาสีที่เหมาะกับตัวเอง แล้วนำผลนั้นไปเลือกดูสินค้า จัดลุค และซื้อสินค้าได้ในเส้นทางเดียว ความสำเร็จของผลิตภัณฑ์คือผู้ใช้เข้าใจสีของตน เลือกสินค้าที่มั่นใจ และทำรายการซื้อได้โดยไม่สับสน

## Positioning

แคตตาล็อกของ MatchA จัดสินค้าโดยให้ “สีที่เข้ากับผู้ใช้” เป็นกลไกหลักในการค้นพบ ไม่ได้ใช้สีเป็นเพียงตัวกรองตกแต่ง ผู้ใช้สามารถเชื่อมจากผล personal colour ไปยังเฉดและสินค้าจริงในคลังได้

## Operating Context

ผู้ใช้เข้าจากหน้าแรก ผลวิเคราะห์ personal colour หรือหน้า lookbook แล้วค้นหา กรองตามสี หมวดหมู่ ทรง ฤดูกาล ราคา และสถานะสินค้า ก่อนเปิดรายละเอียด เลือกตัวเลือก และเพิ่มลงตะกร้า ผู้ดูแลระบบจัดการสินค้าและสต็อกผ่านข้อมูลเดียวกับหน้าร้าน

## Capabilities and Constraints

- React และ Tailwind CSS บนเว็บที่ responsive
- ใช้ข้อมูลสินค้าและรูปภาพจริงจาก API เดิม
- ต้องรักษาการค้นหา หมวดหมู่ ตัวกรองสี ตัวกรองละเอียด การเรียงลำดับ pagination, quick view และ add to cart
- ลิงก์สีจากผล personal colour ใช้ query parameter `dye` และต้องแชร์หรือ bookmark ได้
- รองรับภาษาไทยและอังกฤษผ่านระบบภาษาปัจจุบัน
- ห้ามสร้างคำกล่าวอ้างทางธุรกิจ รีวิว หรือข้อมูลสินค้าที่ไม่มีในระบบ

## Brand Commitments

- ชื่อและโลโก้ MatchA
- แบรนด์เชื่อม personal colour เข้ากับแฟชั่น ลุค และความมั่นใจที่มองเห็นได้จริง
- น้ำเสียงสร้างสรรค์ กล้า มีพลัง และร่วมสมัย โดยยังต้องอ่านและซื้อสินค้าได้ง่าย
- สีของเสื้อผ้าและเฉดจริงเป็นเนื้อหาหลักของประสบการณ์

## Evidence on Hand

- ข้อมูลสินค้า ราคา สี variants ทรง ฤดูกาล สต็อก และรูปภาพจาก API ปัจจุบัน
- โลโก้และภาพสินค้าใน repository
- หน้า personal colour, lookbook, cart, checkout และ catalog ที่ทำงานอยู่
- ไม่มี testimonial หรือข้อมูลประสิทธิผลของการวิเคราะห์สีที่ยืนยันแล้ว จึงไม่ควรสร้างขึ้นเอง

## Product Principles

- ให้สีจริงนำทางการค้นพบสินค้า
- ทำให้ทุกการทดลองกรองย้อนกลับและเข้าใจได้ทันที
- แสดงสินค้าเป็นลุคที่นึกภาพสวมใส่ได้ พร้อมข้อมูลซื้อที่ชัดเจน
- ใช้ความสร้างสรรค์เพื่อช่วยตัดสินใจ ไม่บดบังงานซื้อสินค้า
- เชื่อมทุกหน้าเป็นเส้นทางเดียวจากการค้นพบตัวเองไปสู่การเลือกซื้อ

## Accessibility & Inclusion

สีต้องมีชื่อและสถานะข้อความเสมอ ไม่สื่อความหมายด้วยสีเพียงอย่างเดียว ส่วนควบคุมทั้งหมดต้องใช้คีย์บอร์ดได้ มี focus state และรองรับ reduced motion
